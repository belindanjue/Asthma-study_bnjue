# 🌎 Asthma Patterns in California: A Geospatial and Temporal Analysis

An interactive study of asthma-related emergency department visits across California (2013–2022).

---

## 🚀 Project Overview

This project investigates asthma ED visit patterns using demographic and geographic data.  
Dynamic maps and charts are built to explore:

- Regional distribution of asthma ED visit counts and rates.
- Changes in visit trends by age groups.
- Identifying high-risk populations and regions.
---

## 📦 Datasets

- [Asthma ED Visit Rates by County](https://catalog.data.gov/)
- [Asthma ED Visit Rates by ZIP Code](https://catalog.data.gov/)
- [ZIP-level Asthma Rates by Age Groups](https://catalog.data.gov/)
- California county and ZIP shapefiles.

---

## 📈 Key Findings

- **Los Angeles County** leads in asthma ED visits.
- **San Francisco Bay Area** has the highest adjusted visit rates.
- **Children** represent a large portion of asthma ED visits, especially before 2020.
